Drop your personal tennis & pickleball photos here.

The carousel lives in src/components/TennisCarousel.tsx.
For each slide, set `image` to a path under /public, e.g.:

  { sport: 'tennis', location: 'london, uk', image: '/images/beyond/wimbledon.jpg' }

Recommended: landscape photos around 1200x900 (4:3). Any slide without an
`image` shows an on-brand gradient placeholder so the carousel still looks good.
